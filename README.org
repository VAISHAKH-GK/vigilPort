* Introduction

VigilPort is a lightweight port scanning tool built with Go, featuring a graphical user interface developed using MyGo.

The project aims to identify open ports on a target host by scanning a specified range of TCP ports. It is intended as a learning project to explore network programming, TCP connections, port scanning techniques, and Go application development.

* Features

+ Scan TCP ports on a target host.
+ Specify custom port ranges.
+ Identify open ports.
+ Display scanning results through a graphical interface.
+ Lightweight and simple to use.

* Technology Used

+ =Go= – Core scanning engine and backend.
+ =MyGo= – Graphical user interface.
+ =TCP/IP= – Network communication and port scanning.
